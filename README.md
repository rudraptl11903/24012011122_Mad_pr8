## 📌 Overview
**Aim:** Create your first "Hello World" iOS application using **SwiftUI** and **Xcode**.

This practical covers:
1. Setting up a new iOS App project in Xcode using Swift and SwiftUI.
2. Understanding the core structure of a basic SwiftUI app (`App` protocol, `Scene`, `WindowGroup`, and `ContentView`).
3. Running the iOS application in the Xcode Simulator and using live SwiftUI Previews (`PreviewProvider`).
